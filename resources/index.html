macOS input method public

BiLing

Native macOS pinyin input method: a 1.44M-entry dictionary engine decodes every keystroke in milliseconds, and a local Qwen3-0.6B re-ranks the candidates using the text before the cursor, but only when a calibrated gate expects the dictionary to be wrong. On a held-out corpus it lifts accuracy from 37.8% (dictionary only) to 46.1%, and it matches Apple Pinyin once there is context. Learning is AES-GCM encrypted on the Mac, and the app has no network access at all.

formal mathematics public

erdos-488-lean

Lean 4 results around Erdős problem 488 on primitive sets. It proves the original density inequality for every primitive generator set with excess at most 15, shows that 16 is exactly where the auxiliary estimate first fails, and refutes two conjectures from a March 2026 manuscript with explicit counterexamples. The proofs, found with a Codex multi-agent workflow, use no sorry or native_decide; the full problem remains open.
